# Business Inventory Management

A modern business dashboard for managing products, inventory, suppliers, sales, and reports.

## Features

- Inventory overview dashboard
- Product catalog tracking
- Low-stock monitoring
- Supplier information section
- Sales and transaction management
- Report and analytics views
- Business settings panel

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Lucide Icons

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app locally:
   ```bash
   npm run dev
   ```

3. Open your browser at:
   ```bash
   http://localhost:3000
   ```

## Pages

- `/` — Dashboard overview
- `/products` — Product catalog
- `/inventory` — Inventory status and movements
- `/suppliers` — Supplier management
- `/sales` — Sales transactions
- `/reports` — Reports and analytics
- `/settings` — Business settings
